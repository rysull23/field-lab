# Field Lab

Interactive 2D vector-field laboratory. Edit Px and Py, watch arrows and particles respond immediately, hover for a live readout.

**Open the app:** https://cdn.jsdelivr.net/gh/rysull23/field-lab@main/index.html

## Try

- Switch presets (vortex, saddle, pendulum, van der Pol, gyre)
- Edit the equations — the field updates as you type
- Hover the canvas for (x, y), F, and |F|
- Click to drop a tracer particle
- Scroll to zoom, drag to pan, Space to play/pause
